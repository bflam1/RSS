Mend.io Unified Release Notes

Mend AppSec Platform: Version 26.5.2 (14-June-2026)

2026-06-14T00:00:00+00:00

New Features and Updates

  • Finding details in Mend for JetBrains now display correctly on narrow panels. Labels now stack vertically, keeping the information clear and legible regardless of how wide the panel is.

  • (SCA) The Dependencies Findings Report — Org-level report generation is now backed by a new scalable reporting pipeline, resolving timeouts and failures experienced by large organizations.

  • (SCA) The Dependencies Risk report is now available at the organization level in the Mend Platform UI.

Resolved Issues

  • Fixed an issue where active users accessing the Mend Platform via SSO were incorrectly displayed with an "Invited" status instead of "Active" in the Users section. This status now correctly reflects the user's activity.

  • Fixed an issue where Mend CLI scans failed with a timeout error during policy compliance checks. This occurred when backend processing for specific large datasets exceeded the client-side deadline. The fix optimizes server-side policy evaluation to ensure scans complete successfully within the expected timeframe.

  • (Container) Fixed an issue where workflow violations were incorrectly triggered for suppressed findings during CLI image scans. Suppressed vulnerabilities are now properly excluded from workflow evaluation, ensuring that automated policies and CLI exit codes accurately reflect the project's security status.

  • (Container) Fixed an issue where the total number of container findings in the Project Summary did not match the totals shown in the Security > Containers > Findings page, ensuring consistent and accurate reporting across views.

Mend SAST: Version 26.5.2 (15-June-2026)

2026-06-15T00:00:00+00:00

New Features and Updates

  • Extended the support for JWT callbacks and anonymous classes in Java.

  • Improved detection of CWE-79: Cross-site Scripting (XSS) in JavaScript/TypeScript.

  • Improved detection of hard-coded credentials for JavaScript/TypeScript, PL/SQL, and VB.Net.

  • The SAST findings API now includes natural language descriptions for each step in a vulnerability's data flow trace. When retrieving a finding, each step in the data flow — from the tainted input to the vulnerable sink — now comes with a plain-English explanation of what's happening at that point in the code.

Resolved Issues

  • Fixed an issue where Chinese characters wouldn't be displayed correctly in the PDF version of the Code Compliance Report.

  • Finding details in Mend for JetBrains now display correctly on narrow panels. Labels now stack vertically, keeping the information clear and legible regardless of how wide the panel is.

Mend AI: Version 25.12.1 (05-January-2026)

2026-01-05T00:00:00+00:00

New Features and Updates

  • (Premium / Core) Introducing System Prompt Risk (open beta), a new detection and remediation offering by Mend AI, for mitigating risks posed by system prompts used in conversational AI interfaces.

    • A new System Prompt Risk table inventories system prompts and provides quick export/sharing and deep-link side panel for prompt context.

    • System Prompt Risks are integrated into the existing AI Security Risk Factors across Projects and Applications. The classification appears as a Conversational Interface chip, is filterable, and automatically participates in dashboards and workflows.

    • Remediation in the form of a hardened system prompt is available in the System Prompt side panel, providing clear, copy-ready remediation guidance for AppSec engineers and developers.

    • The AI Security Dashboard has been enriched with system prompt risk data.

    • System prompt risk data is also available via API.

Mend Unified Agent: Version 26.5.2 (15-June-2026)

2026-06-15T00:00:00+00:00

Resolved Issues

  • Fixed an issue where the Unified Agent failed to resolve npm dependencies in pnpm/Lerna monorepos that lacked a `package-lock.json` file. The resolution logic has been updated to correctly identify pnpm in Lerna configurations and utilize the `pnpm-lock.yaml` file, ensuring all dependencies are accurately detected and reported.

  • Fixed an issue where the npm resolver produced duplicate dependency entries when the same package was reachable via multiple ancestor chains. The resolver now correctly identifies and deduplicates identical packages regardless of their position in the dependency tree, ensuring accurate scan results and preventing duplicate vulnerability findings in the platform.

Mend Developer Platform: Version 26.5.2 (14-June-2026)

2026-06-14T00:00:00+00:00

New Features and Updates

  • When adding or removing repos from the Renovate app installation in GitHub, users no longer go through the Developer Platform onboarding flow. Instead, they are redirected to the Developer Platform UI and the repositories are onboarded according to the existing organization settings.

  • (Renovate) Introduced enhanced customization in Renovate Enterprise Cloud, enabling organizations to run custom scripts and configure environment variables and headers. These new capabilities provide greater flexibility and control for enterprise users.

Resolved Issues

  • (Bitbucket) Fixed an issue where Bitbucket installation events for non-reinstalls could incorrectly trigger the de-onboarding of organizations. The system now properly verifies the uninstallation status before removing onboarding data, ensuring that app updates or other standard events do not disrupt the customer's environment.
