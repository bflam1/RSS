Mend.io Unified Release Notes

Mend AppSec Platform: Version 26.10.1 (01-November-2026)

2026-11-01T00:00:00+00:00

New Features and Updates

  • (Open Beta) Introducing Mend Intelligent Agent, an AI-powered assistant embedded within the Mend Platform. Users can now interact using natural language to explore platform capabilities, receive guidance to relevant views, and obtain executive-level risk summaries. This feature provides a centralized organizational perspective, enabling security teams to identify and prioritize critical findings across all applications and projects efficiently. Mend Assist streamlines security oversight by delivering instant, actionable insights and automated navigation, all within the existing platform workflow.

    • The feature is enabled by default for organizations with signed AI consent via an addendum in your Mend.io contract. For organizations without consent, the feature remains disabled. Please contact your Customer Success Manager for more details.

  • (SAST) Introduced granular control for low-probability scan categories within the Scan Profile. Users can now selectively include or exclude specific categories, such as File Read or Database Read, to refine detection and reduce noise. This update replaces the previous binary toggle with a configurable selection tree, allowing for self-service tuning tailored to specific codebase requirements. Changes are applied to the next scan and include a count indicator for selected categories.

Resolved Issues

  • (SCA) Fixed an issue where certain vulnerability findings remained open in the Mend Platform even after the underlying CVE association was removed from the database.

  • (SCA) Fixed an issue where vulnerability trace data was duplicated during the write process, leading to excessive database growth and potential memory exhaustion during scans.

  • (SCA) Fixed an issue where `.pom` files were incorrectly reported as independent libraries in scan results. These metadata descriptors are now excluded from the inventory, preventing false positives and ensuring that CI/CD pipelines are not blocked by unknown license alerts for non-library artifacts.

  • (SAST) Fixed an issue where Code report downloads failed in Chromium-based browsers, such as Chrome and Edge, when the organization name contained a comma.

Mend SAST: Version 26.10.1 (02-November-2026)

2026-11-02T00:00:00+00:00

New Features and Updates

  • Introduced granular control for low-probability scan categories within the Scan Profile. Users can now selectively include or exclude specific categories, such as File Read or Database Read, to refine detection and reduce noise. This update replaces the previous binary toggle with a configurable selection tree, allowing for self-service tuning tailored to specific codebase requirements. Changes are applied to the next scan and include a count indicator for selected categories.

  • Added support for custom Node.js routing frameworks where entry points are defined in `routes.json` files. This update enables the engine to parse these manifests and correctly identify handler functions as entry points for taint analysis, ensuring comprehensive vulnerability detection for non-standard routing configurations.

Resolved Issues

  • Fixed an issue in the CLI where Go scans experienced significant performance degradation and timeouts when analyzing generated protobuf (.pb.go) files. The analysis process is now optimized, resulting in substantially faster scan completion times for projects containing these files.

  • Fixed an issue where some Swagger YAML entry points were not correctly detected during scans. The engine now correctly parses Swagger YAML files to identify all API endpoints, ensuring comprehensive vulnerability coverage and accurate reporting for applications using Swagger-generated code.

  • Fixed an issue where Code report downloads failed in Chromium-based browsers, such as Chrome and Edge, when the organization name contained a comma.

Mend AI: Version 25.12.1 (05-January-2026)

2026-01-05T00:00:00+00:00

New Features and Updates

  • (Premium / Core) Introducing System Prompt Risk (open beta), a new detection and remediation offering by Mend AI, for mitigating risks posed by system prompts used in conversational AI interfaces.

    • A new System Prompt Risk table inventories system prompts and provides quick export/sharing and deep-link side panel for prompt context.

    • System Prompt Risks are integrated into the existing AI Security Risk Factors across Projects and Applications. The classification appears as a Conversational Interface chip, is filterable, and automatically participates in dashboards and workflows.

    • Remediation in the form of a hardened system prompt is available in the System Prompt side panel, providing clear, copy-ready remediation guidance for AppSec engineers and developers.

    • The AI Security Dashboard has been enriched with system prompt risk data.

    • System prompt risk data is also available via API.

Mend for GitHub Enterprise: Version 26.10.1.1 (01-November-2026)

2026-11-01T00:00:00+00:00

Unified Agent 26.9.2.1 | Renovate 44.176.3 | Remediate 26.9.3.3 | Pre-Scan Builder (PSB) 25.8.1

New Features and Updates

  • (SAST) Introduced a new configurable parameter controlled by skipSupersededResults that allows skipping SAST scans when a newer commit to the same branch supersedes them. This optimization prevents unnecessary processing time for outdated scans, particularly in large repositories, and updates the check run status to inform users that the stale scan was bypassed in favor of the most recent version.

  • (SAST) Improved check-run error messages for cloning failures to provide specific details when a scan fails due to a missing branch, unavailable commit, inaccessible repository, or cloning timeout.

  • (SAST) Optimized the repository scanning process by removing redundant configuration flags for multi-base branch support. The system now automatically sets the required repository identification parameters.

  • Updated Mend documentation to provide validated recommendations for scanner memory sizing while maintaining scan stability and performance when running Reachability scans.

Resolved Issues

  • (SAST) Fixed an issue where the license check run failed for projects containing more than 100 libraries.

  • (SAST) Fixed suppression requests that could get stuck in Pending and couldn't be approved or rejected. This happened mainly when the finding had already been resolved on the base branch before the reviewer acted.

  • (SAST) Fixed suppression requests failing for findings on feature branches that were detected in stale base branch scans.

  • (SAST) Fixed an issue where the scanner image bundled end-of-life Node.js versions. The image now includes Node.js 26.x, an LTS version supported until April 2029, ensuring compliance with software lifecycle policies.

  • (SCA) Fixed an issue where scanSummaryInfo values, including per-step statistics and failure reasons, were missing from enriched update requests during Reachability scans. The enriched request now correctly retains all original metadata while including the vulnerability analysis results.

  • (SCA) Fixed an issue where JavaScript Reachability enrichment failed for projects with `devEngines` requirements that did not match the scanner's Node.js version. The enrichment process now uses the `--force` flag for metadata retrieval to ensure compatibility regardless of local engine constraints. Additionally, error reporting was improved to include specific npm error codes, and sensitive credential information was removed from command logs to enhance security.

  • (SCA) Fixed an issue where the Conda resolver incorrectly identified any file named `environment.yaml` or `environment.yml` as a Conda manifest based solely on the filename. This caused non-Conda files to be processed, potentially leading to spurious dependency findings. The resolver now validates the file schema to ensure it contains valid Conda keys before proceeding with resolution.
